# Changelog

## 0.1.0 — foundation

- Added C++20 / Qt 6 desktop shell and honest format capability registry.
- Added bounded, read-only UTF-8 text reader and word count.
- Added Termux build scripts and Windows/Linux GitHub Actions workflows.
- Documented unsupported engines and current limitations.

## 0.2.0 — PDF reading

- Added an optional Qt PDF/PDFium reading workspace with page modes, zoom, full-text search highlighting, search-result navigation, protected-file password prompt, and extracted text export.
- Added qtpdf to the Windows CI dependency set and capability reporting follows the modules present in the build.
