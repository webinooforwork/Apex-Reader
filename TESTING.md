# Testing

The `document_basics` test exercises extension normalization, registered support, UTF-8 text reading, word counting, and file-open errors. When Qt PDF is installed, `pdf_engine` loads a generated one-page PDF, checks page count and extracted text, then rejects malformed input. Windows and Linux CI build and run the tests available in their dependency set. The docx_engine test builds a compressed OOXML ZIP fixture, verifies heading, paragraph, and table text extraction, rejects DTD content, and rejects malformed ZIPs. Database, OCR, and comparison coverage remains to be added. `scripts/run_tests.sh` builds and runs CTest.
